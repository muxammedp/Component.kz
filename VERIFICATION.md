# Проверка Component.kz

Дата: 12 октября 2026 г. Windows, Node.js v24.18.0, встроенная SQLite, установленный Google Chrome в headless-режиме.

## Сервер и сохранение данных

`npm.cmd test` — **52 / 52 PASS**, 0 ошибок (HTTP API, сохранение данных, правила сборки и поиск).

- Регистрация, вход, неверный пароль, повторный email, HttpOnly / SameSite-сессии, выход.
- Авторизация записи, изоляция аккаунтов и запрет межсайтовых запросов.
- Создание и редактирование объявления, проверенная привязка модели, сохранение и удаление фото. Некорректное редактирование не меняет объявление.
- Изменение снятого с продажи объявления не активирует его автоматически.
- Избранное, сохранённые сборки, оценка совместимости, бюджет и условия автоматического подбора.
- Серверный итог заявки и фиксированные цены после изменения объявления.
- Проверка ожидаемых цен при отправке: изменившаяся цена возвращает 409 без создания заявки; некорректные ожидаемые цены возвращают 400.
- В заявке с двумя продавцами каждый видит только свои товары, сумму и ответ; посторонний пользователь не получает доступ.
- Независимые ответы продавцов, принятие, отклонение, завершение и отмена покупателем. Недопустимые переходы возвращают 409.
- Заявки на сборку не рассылаются продавцам отдельных компонентов.
- Устаревшие объявления и дублирующиеся ID не принимаются при оформлении.
- Файловая SQLite: аккаунт, сессия, сборка, отредактированное объявление и ответ продавца переживают перезапуск. Проверено восстановление связей продавцов для старых заявок без сброса уже сохранённых ответов.
- `.env`, база и серверный исходный код недоступны по HTTP.
- Поиск моделей без пробелов и с другим порядком слов, русские варианты, характеристики, исправление раскладки, подсказки при опечатках. Проверен запрет приблизительного совпадения чисел моделей.
- Сочетания фильтров, корректные счётчики, параметры с несколькими значениями, сортировка цен и разбор вставленной цены с пробелами.
- Поиск реального объявления по привязанной модели с проверкой категории и существования модели; единицы измерения с правильными значениями; сохранение общих ограничений при уточнении категории без изменения исходного объекта фильтра.

## Браузер

`npm.cmd run test:browser` — **161 проверка PASS**, 0 исключений JavaScript.

Проверки используют Chrome DevTools Protocol и отдельную базу в памяти:

- Темы: переключение, сохранение после перезагрузки, приоритет явного выбора и реакция системного режима на изменение настройки устройства. Проверены цвета карточек, полей и модального окна; сохранены снимки главной, каталога, сборщика, заявки и мобильных фильтров.
- Реальные события колеса через Chrome DevTools: промежуточные позиции плавной прокрутки и точная остановка, изменение параллакса от скролла и мыши, отмена движения при навигации. Прокрутка внутри фильтров остаётся нативной; Ctrl+wheel не перехватывается; отключение эффектов возвращает нативное поведение.
- Движение: анимация главного баннера, немедленное отключение, сохранение настройки, следование `prefers-reduced-motion` в системном режиме и явное включение эффектов вопреки этой настройке, плавный возврат наверх. Оба системных режима явно эмулируются, поскольку на текущем устройстве уменьшение движения включено.
- Пропорции SVG-иллюстраций: одинаковый масштаб по обеим осям в GPU/CPU-каталоге, карточке товара, сборщике, корзине и сравнении. Для фотографий объявлений сохранён `object-fit: contain`.
- Главная, поиск, корзина, регистрация, избранное, публикация объявления.
- Полная совместимая сборка, сохранение конфигурации, заявка на сборку.
- Переход из поиска в другую категорию без оставшегося старого запроса.
- Фильтры в URL, перезагрузка, кнопка «Назад», удаление фильтра и сброс пустой выдачи.
- Сравнение двух видеокарт, запрет смешивания категорий, режим различий, сохранение выбора после перезагрузки.
- Точный бюджет 487 321 ₸ без округления.
- Редактирование объявления, предпросмотр загруженного PNG, сохранение и восстановление фотографии и модели.
- Своё объявление предлагает редактирование вместо покупки.
- Покупатель отправляет заявку, смотрит состав; продавец принимает её; покупатель видит ответ и отменяет; у продавца исчезают недоступные действия.
- Мобильная нижняя навигация.
- Продолжение покупки после регистрации с составом и ценами в форме.
- Локальный черновик нового объявления после перехода и перезагрузки, подтверждённый сброс, явное восстановление черновика редактирования и разделение по аккаунтам.
- Каталог по 12 товаров, сохранение страницы при перезагрузке, возврат к первой странице при сортировке.
- Изменение цены другим продавцом при открытой форме: блокировка отправки, обновление суммы без потери телефона и комментария, успешная повторная отправка.
- Проверка недоступного товара до сбора контактов.
- Пять ранее неработающих поисковых запросов, видимое исправление раскладки, переход по подсказке опечатки.
- Сохранение ограничений при уточнении поиска и явный переход к поиску по всему каталогу.
- Счётчики брендов/состояний с учётом остальных условий; фильтрация видеопамяти и сокета, URL, перезагрузка и снятие отдельного параметра.
- Восстановление результатов из пустой выдачи снятием только ограничения города.
- Цена с пробелами, ошибка диапазона около поля, разделение реальных и демо-объявлений.
- Мобильная панель не закрывается после выбора; неприменённая цена сохраняется, кнопка результатов закрывает панель и переводит фокус к выдаче.
- Поиск мощности и частоты, поиск объявления с общим заголовком по выбранной модели, отображение названия этой модели.
- Уточнение категории с сохранением запроса, бюджета и сортировки, снятие несовместимых параметров без пустой выдачи из-за старых ограничений.
- Поиск по брендам, сохранение строки после выбора, видимость выбранных брендов, очистка только строки поиска, работа на телефоне.
- Возврат из карточки после её перезагрузки к прежнему URL выдачи, странице, сортировке, фокусу и позиции прокрутки.
- Отсутствие горизонтального переполнения документа на 12 страницах при 360, 390, 768 и 1440 px. Таблица сравнения имеет собственную горизонтальную прокрутку.

Визуально просмотрены скриншоты сравнения, редактора объявления, профиля и заявок, в том числе мобильные; во втором проходе — восстановленный черновик и форма с изменившейся ценой. Скриншоты актуального прогона сохранены в `screenshots/`; фотография в тестовом объявлении — искусственный синий PNG для проверки загрузки, не изображение товара.

Серверные и браузерные тесты не используют основную базу проекта. Тест перезапуска создаёт отдельную временную SQLite и удаляет её после проверки.

- Оплата, доставка, внешние уведомления, восстановление пароля и кабинет оператора-сборщика не реализованы.
- Не проводились нагрузочный аудит, полноценный аудит безопасности и испытания в Safari/Firefox или на физических телефонах.
- Публичное размещение не выполнялось.
