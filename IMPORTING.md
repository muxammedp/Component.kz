# Справочник комплектующих

Открой http://127.0.0.1:3000/#models. Справочник хранится в `data/component.sqlite`, отдельно от объявлений. При первом запуске используются поставляемые снимки Intel/AMD; интернет для запуска сайта не нужен.

## Обновление Intel и AMD

```powershell
npm.cmd run models:sync -- --dry-run
npm.cmd run models:sync
```

Первая команда проверяет загрузку, разбор и количество изменений без записи импортируемых моделей. Инициализация отсутствующей схемы и перенос старого локального справочника выполняются даже при dry-run. Вторая команда применяет изменения. При недоступности одного источника другие обрабатываются, команда завершается ненулевым кодом. Обновления разных источников независимы; импорт внутри каждого источника атомарный. Смена формата таблицы вызывает ошибку, существующие записи не удаляются.

Можно запускать `models:sync` из планировщика раз в неделю с рабочим каталогом проекта. Автоматическое задание Windows не установлено. Уже открытая вкладка увидит новые модели после обновления страницы; сервер перезапускать для импорта не нужно.

```powershell
npm.cmd run models:import -- amd-cpu
npm.cmd run models:import -- amd-gpu
npm.cmd run models:import -- intel
npm.cmd run models:import -- intel --file "C:\Downloads\intel.xlsx" --dry-run
```

`--file` принимает исходный HTML AMD или XLSX Intel. `--snapshot путь.json` сохраняет нормализованные записи для архива; существующий файл по указанному пути перезаписывается. Исходные файлы автоматически не сохраняются. На снимках в `data/reference/` есть описание покрытия и даты получения.

## Подключение Open Icecat

1. Зарегистрировать собственный аккаунт Open Icecat.
2. Создать `.env` на основе `.env.example` и локально заполнить `ICECAT_USERNAME`, `ICECAT_API_TOKEN` из MyIcecat → Access Tokens. Не передавать токен через аргументы команд и не коммитить `.env`.
3. Использовать настоящий ID товара из Icecat и категорию проекта:

```powershell
npm.cmd run models:import -- icecat --id YOUR_PRODUCT_ID --category gpu --dry-run
npm.cmd run models:import -- icecat --id YOUR_PRODUCT_ID --category gpu
```

Вместо YOUR_PRODUCT_ID нужен числовой ID. Категории: `cpu`, `gpu`, `board`, `ram`, `ssd`, `psu`, `case`, `cooler`. Адаптер проверяет английское название категории в ответе; неизвестные категории требуют дополнения соответствия. API запрашивается на английском, токен передаётся только заголовком `api-token`. Данные недоступных по подписке товаров не обходятся. Неподтверждённые единицы или характеристики не участвуют в совместимости. Партнёрские GPU идентифицируются брендом и артикулом, а не только названием чипа.

Одна команда загружает одну карточку. Импорт глобального/дневного индекса Icecat, изображения и массовый график синхронизации пока не подключены. Данные для входа отсутствуют, поэтому реальный запрос Icecat в этом окружении не проверялся; адаптер проверен на ответе формата из документации. Для проверки сохранённого ответа доступен `--file card.json --category gpu`.

Карточки с этим источником содержат ссылку Specs Icecat и оговорку «как есть». Данные не используются для обучения ИИ. Условия и доступность контента зависят от подписки и производителя.

Документация: [Icecat JSON](https://iceclog.com/manual-for-icecat-json-product-requests/), [автоматизация и условия](https://iceclog.com/manual-how-to-import-product-content-into-your-webshop-via-icecat/).

## Другие источники и заявки

`npm.cmd run models:import -- manual --file models.json --dry-run` принимает массив записей следующего вида:

```json
[
  {
    "externalId": "manufacturer-part-number",
    "category": "ram",
    "brand": "Manufacturer",
    "title": "Exact manufacturer model",
    "mpn": "manufacturer-part-number",
    "url": "https://manufacturer.example/product",
    "spec": {"ram": "DDR5", "size": 32, "speed": 6000}
  }
]
```

После проверки убрать `--dry-run`. Импортируемые записи не получают расчётные баллы и подтверждение совместимости автоматически. Источник и внешний ID стабильны; повторная загрузка обновляет ту же модель. Изменение категории существующей записи отклоняется. Нельзя использовать один externalId для разных товаров.

Заявки на отсутствующие модели сохраняются после входа на странице справочника. Для локального оператора: `npm.cmd run models:requests`. Список не публикуется через API. Заявка сама по себе не добавляет модель; после проверки оператор может импортировать фактические характеристики. Интерфейса модерации и изменения статусов заявок пока нет.

## Проверки

```powershell
npm.cmd test
npm.cmd run test:browser:directory
```

Браузерный тест требует установленный Chrome; использует отдельный сервер с SQLite в памяти. Не запускайте его параллельно с остальными браузерными тестами: общий порт Chrome 9333.
