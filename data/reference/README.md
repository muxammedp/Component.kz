# Снимок официальных справочников, 12 октября 2026

Файлы содержат нормализованные фактические характеристики, а не объявления, изображения или результаты бенчмарков. При первом запуске сервер импортирует отсутствующие источники в SQLite. Повторный запуск не откатывает обновлённые данные к этому снимку.

| Файл | Исходных записей | Источник |
| --- | ---: | --- |
| amd-cpu.json | 388 | https://www.amd.com/en/products/specifications/processors.html |
| amd-gpu.json | 37 | https://www.amd.com/en/products/specifications/graphics.html |
| intel.json | 304 | https://www.intel.com/content/www/us/en/support/articles/000005505/processors.html |

AMD: извлечены значения из публичной таблицы `data-json`; CPU ограничены настольными сокетами AM/FM/TR/sWRX, GPU — значением Desktop. Фильтрация сокета нужна, поскольку некоторые мобильные CPU в исходной таблице также имеют пометку Desktops. Intel: официальный Excel по настольным процессорам, колонки проверяются перед импортом; обновлённый URL файла при необходимости меняется в `imports/sources.mjs`.

729 исходных записей добавляют 708 новых моделей и связывают 21 запись с существующими CPU. Итоговая база с локальными моделями содержит 795 записей, включая 695 CPU и 50 GPU. Это ограниченное покрытие, не все модели в истории. GPU AMD здесь — базовые модели AMD, а не все исполнения ASUS/MSI и других партнёров. NVIDIA и другие комплектующие пока представлены прежними локальными моделями; расширение через Icecat требует аккаунта.

TDP хранится отдельно от максимального потребления, не подставляется вместо него. Отсутствующая характеристика не заполняется предположением. Внешние спецификации и существующий демонстрационный расчётный профиль хранятся отдельно. Импорт не добавляет оценки мощности, FPS, цены или объявления. Права на исходные материалы принадлежат их владельцам; эти файлы не предоставляют отдельной лицензии на их контент.
